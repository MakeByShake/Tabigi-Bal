# Как включить админку (≈5 минут)

Админка открывается по адресу **https://tabigi-bal.vercel.app/admin**.
Чтобы она заработала, в Vercel нужно один раз подключить базу, хранилище фото и задать пароль.
Пока этого не сделать, сайт работает как раньше: товары показываются из кода, заказы уходят в WhatsApp.

## 1. База данных (товары и заказы)
1. Откройте https://vercel.com, выберите проект **tabigi-bal**.
2. Вкладка **Storage**, затем **Create Database**.
3. Выберите **Neon** (Serverless Postgres), затем **Continue**. Регион: **Frankfurt** (ближе всего к Казахстану). Тариф **Free**.
4. На шаге «Connect to project» выберите **tabigi-bal** и все окружения (Production, Preview, Development), затем **Connect**.
   Vercel сам добавит переменную `DATABASE_URL`.

## 2. Хранилище фото
1. Снова **Storage**, затем **Create Database**, затем **Blob**, затем **Continue**.
2. Название любое, например `tabigi-photos`, затем **Create**.
3. **Connect to project**, выберите **tabigi-bal** и все окружения, затем **Connect**.
   Vercel сам добавит переменную `BLOB_READ_WRITE_TOKEN`.

## 3. Пароль от админки
1. **Settings**, затем **Environment Variables**.
2. Key: `ADMIN_PASSWORD`, Value: ваш пароль (не короче 10 символов, не используйте его где-то ещё).
3. Отметьте все окружения и нажмите **Save**.

## 4. Перезапуск
**Deployments**, у самого верхнего деплоя нажмите **⋯**, затем **Redeploy**.
Через 1–2 минуты откройте `/admin` и войдите с паролем.

При первом входе в базу автоматически перенесутся текущие 19 товаров.

## 5. Уведомления о заказах в Telegram (по желанию)
В админке: **Настройки**, затем **Telegram-уведомления**. Там пошаговая подсказка: создать бота у @BotFather, вставить токен, нажать Start у бота, затем «Найти чат».

## Что умеет админка
- **Заказы**: все заказы с сайта с номером (TB-1234A, такой же номер в сообщении WhatsApp), статусы «Новый, Подтверждён, Выполнен, Отменён», выручка за сегодня, 7 и 30 дней, топ товаров.
- **Товары**: добавить, изменить или удалить; фото с телефона (сжимается автоматически); наличие «Есть / Мало / Нет»; скрыть с сайта; порядок; фасовка (1 кг); скидка (старая цена зачёркнута, на фото «−%»); метки «Жаңа», «Хит» и другие.
- **Настройки**: телефон, номер WhatsApp для заказов, адрес, часы, текст о доставке, ссылки на соцсети, полоса объявления над сайтом.

Если товар закончился, ставьте **«Нет»**, а не удаляйте его. Он останется на сайте серым с кнопкой «Келгенде хабарла», и клиент напишет вам в WhatsApp.

## Смена пароля
Поменяйте `ADMIN_PASSWORD` в Vercel и сделайте Redeploy. Все, кто был залогинен, выйдут автоматически.

## Локальный запуск для разработчика
```bash
npm install
npm run dev        # сайт: http://localhost:5173, админка: /admin, пароль по умолчанию: admin
```
Локально используется встроенный Postgres (папка `.data`), а фото сохраняются в `public/uploads`. Обе папки не попадают в git.
