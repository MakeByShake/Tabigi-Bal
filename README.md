# Tabigi Bal

An online shop for natural honey, in Kazakh. Visitors browse honey types, add them to a cart and see the total.

**Live:** https://tabigi-bal.vercel.app

**Stack:** React, Vite, CSS, Context API

## Features

- Product catalog with descriptions and prices
- Cart panel: add, remove, change quantity, total price
- Notifications when an item is added
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```
